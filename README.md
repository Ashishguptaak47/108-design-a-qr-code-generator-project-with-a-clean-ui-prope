# QR Code Studio

A modern desktop application built with Python and Tkinter for generating, customizing, and exporting high-quality QR codes.

## Features
- Real-time live preview of generated QR codes
- Custom foreground and background colors
- Adjustable box size and error correction levels (L, M, Q, H)
- Save QR codes to PNG, JPG, or standard image formats
- Built-in error handling and modern GUI styling

## Installation

1. Ensure Python 3.8+ is installed.
2. Install required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the main application:
```bash
python main.py
```

## Running Tests

Execute test suite with pytest:
```bash
pytest
```
